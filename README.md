# 🎮 Super Mario 2D Jump Game

A lightweight, responsive 2D Mario Jump game built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Jump over obstacles, score points, and challenge yourself as the game gets progressively faster!

---

## ✨ Features

- 🖥️ **Full-Screen Responsive Gameplay**: Automatically adapts to full-screen view on laptops, desktops, tablets, and smartphones.
- 🏃 **Realistic Jump Physics**: Smooth 60FPS parabolic jump trajectory with gravity and natural landing using `requestAnimationFrame`.
- 📱 **Mobile & Touch Ready**: Play on mobile devices by tapping anywhere on the screen.
- ⚡ **Dynamic Speed Scaling**: Obstacle speed automatically adjusts to your screen size so you never have to wait too long between jumps on wide screens.
- 📈 **Progressive Difficulty**: Speed increases gradually as your score goes up.
- 🎯 **Fair Hitbox Detection**: Forgiving pixel boundaries for enjoyable gameplay.

## 🚀 How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Anu7276/Mario_game.git
   ```
2. Open the project folder:
   ```bash
   cd Mario_game
   ```
3. Open `index.html` in any modern web browser (Google Chrome, Firefox, Edge, Safari) or use VS Code **Live Server**.
